# Lehrer-App (Programmdateien)

Enthält nur den Programmcode der App, keine Schülerdaten und keine Passwörter.

- `web/` Oberfläche der App (wird von der NAS automatisch abgeholt)
- `server/` Server der App
- `tools/` Quellcode der WebUntis-Lesezeichen
- `tailscale/` Einstellung für den Zugriff von unterwegs

Die Daten liegen ausschließlich auf der NAS im Ordner `data`.
